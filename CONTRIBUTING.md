# Contributing

Thanks for helping improve Agentica.

## How to contribute

- Open an issue or discussion before large changes.
- Keep pull requests focused on one topic.
- Include tests or verification steps when the change affects runtime or UI.
- Follow the existing code style and keep comments concise.

## Branching

- Use feature branches for new work.
- Keep `platform` and `saas` private line changes separated from the public OSS fork.
- Prefer small, reviewable commits.

## Security

- Do not commit secrets.
- Do not trust client-side identity for external integrations.
- Report security issues privately if they affect credentials or tenant isolation.
